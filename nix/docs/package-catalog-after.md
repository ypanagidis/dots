# Package Catalog After Reorganization

This catalogs the package, app, tool, plugin, and runtime library declarations after the package ownership cleanup.

## Summary

| Change | Result |
| --- | --- |
| Root package lists | `configuration.nix` and `home.nix` no longer carry long package lists. They import focused modules. |
| Active packages | Active package declarations were preserved and moved into clearer homes. |
| Browser overlap | `helium`, `chromium`, `google-chrome`, and `firefox` are still all present, now together in the browser module. |
| Electron runtime | `modules/electron.nix` was renamed to `modules/compat/electron-runtime.nix`; `ffmpeg` remains there as a runtime library. |
| User apps | User-facing GUI apps moved from system packages into Home Manager app modules. |
| Inactive Niri tree | Removed from `main`; it remains available on the `multihost-config` branch. |
| Darwin leftovers | Removed from `main`; they remain available on the `multihost-config` branch. |

## Entrypoints

| File | Package responsibility |
| --- | --- |
| `configuration.nix` | Host identity, boot, networking, user account, service toggles, hardware toggles, and imports. No long package list. |
| `home.nix` | Home Manager imports, state version, session path, SSH identity. No long package list. |

## Host-Level Services And Toggles

These are not long package lists, but they still cause NixOS to pull in services, daemons, or program packages. They are kept in `configuration.nix` because they describe this host rather than a reusable package group.

| Declaration | Location | Packages / services / behavior |
| --- | --- | --- |
| Login shell support | `configuration.nix` | `programs.zsh.enable = true` because the user account uses `pkgs.zsh` as its shell. |
| Printing | `configuration.nix` | `services.printing.enable = true` enables CUPS printing support. |
| Avahi / mDNS | `configuration.nix` | `services.avahi` enables local network discovery and address publishing. |
| NordVPN service | `configuration.nix`, `custom-packages/flake.nix` | `services.nordvpn.enable = true` keeps the CLI/daemon usable on demand. Autoconnect should be disabled through NordVPN's own settings. |
| OpenRGB service | `configuration.nix` | `services.hardware.openrgb.enable = true`; CLI package is listed in `modules/system/base-packages.nix`. |
| CoolerControl service | `configuration.nix` | `programs.coolercontrol.enable = true` enables cooler/fan control integration. |

## Generated Hardware Declarations

## Remaining Intentional Duplicates

| Item | Why it remains |
| --- | --- |
| `ffmpeg` and `ffmpeg-full` | `ffmpeg` is an Electron runtime library in `nix-ld`; `ffmpeg-full` is the user-facing CLI. |
| `chromium`, `google-chrome`, `helium`, `firefox` | Kept together in `modules/browsers/default.nix` so browser overlap is visible and easy to trim later. |
| `ripgrep`, `fd`, `lazygit`, `yazi` | Some are global user tools and also Neovim-local tool dependencies; keeping editor-local deps avoids plugin breakage. |
| Electron-ish runtime libs | Wrapper/runtime-specific libs remain with `nix-ld`, Cursor, Helium, and PrismLauncher because each wrapper has its own runtime boundary. |
| `jq` / `curl` script refs | Script refs use absolute store paths for reproducibility even when the tools are also globally installed. |
